01
Introduction & Project Idea
Problem · Goals · Users
Presenter: Team Member 1
The Problem
Schools lacked a unified platform connecting students, instructors, parents, and admins. Progress was tracked manually, communication was fragmented, and parents had no visibility.
Our Solution — TOTC LMS
A full-featured LMS with 5 role-based dashboards, AI-powered tools, automated reporting, and real-time notifications — all in one platform.
System Goals
Streamline course management · Enable AI-assisted learning · Keep parents informed · Automate weekly reports · Provide role-specific dashboards
System Roles
SuperAdmin
Full system control · User management · Configuration
Admin
Monitor activity · Manage users · Announce · Support tickets
Instructor
Create exams · Grade assignments · AI exam generator
Student
Take exams · Submit assignments · AI chatbot · Study planner
Parent
Monitor children · Weekly AI reports · View grades

05
AI Features & Automations
GPT-4o-mini · n8n · Mistral · MongoDB
Presenter: Team Member 5
AI Study Planner
Fetches student's real enrolled courses, upcoming exams & pending assignments from DB. GPT-4o-mini generates a personalized 7-day plan. Never invents subjects.
GitHub Models API · No file needed
AI Exam Generator
Instructor uploads PDF/DOCX → n8n extracts text → Mistral AI generates MCQ + True/False questions with correct answers formatted cleanly.
n8n · Mistral Cloud · multipart/form-data
AI Chatbot (RAG)
Student uploads study material → file sent to n8n webhook → Mistral AI answers questions based ONLY on the uploaded document context.
n8n · Extract from File · Per-request
