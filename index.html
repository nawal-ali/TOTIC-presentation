01
Introduction & Project Idea
Problem Statement · Goals · System Roles
Presenter: Roaa
The Problem
Schools lacked a unified digital platform. Student progress was tracked manually, parent communication was fragmented, and there was no transparency between home and school.
Our Solution — TOTC LMS
A complete web-based LMS with 5 role-specific dashboards, AI-powered learning tools, automated weekly parent reports, a ticketing system, and real-time notifications.
System Goals
Streamline course management
AI-assisted learning tools
Keep parents informed
Automate weekly reports

05
AI Features & Automations
GPT-4o-mini · Mistral AI · n8n · MongoDB
Presenter: Hoor Magdy
AI Study Planner
Fetches student's real enrolled courses, upcoming exam deadlines & pending assignments from DB. GPT-4o-mini generates a 7-day personalized plan — never invents subjects.
GitHub Models API · No file needed
AI Exam Generator
Instructor uploads PDF/DOCX → sent to n8n webhook → Mistral AI extracts text & generates MCQ + True/False questions with correct answers formatted cleanly.
n8n · Mistral Cloud · multipart/form-data
AI Chatbot (RAG)
Student uploads study material → file sent via proxy to n8n webhook → Mistral extracts PDF text → answers questions based ONLY on that document.
n8n · Extract from File · Per-request
